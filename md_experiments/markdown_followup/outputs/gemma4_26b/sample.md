## 4. قطع الاتصال

- `cports /close 192.168.2.14 * 192.168.1.106 * 2548`
    - `cports /close <Local Address>* <Local Port>* <Remote Address> <Remote Port>* {Process Name/ID}`

# 2. الهجمات من طرف الزبون

## Header Manipulation التلاعب بالترويسة

تعتبر ترويسة HTTP جزءاً من طلب HTTP وهي تهتم بخصائص متصفح الزبون ومخدم الويب. يجري نقل المعطيات كنتيجة رسالة طلب HTTP من قبل المتصفح متبوعاً برسالة جواب HTTP من قبل المخدم. يشمل كل الترويسة على اسم الحقل متبوعاً بنقطتين ":" ومن ثم قيمة الحقل. يبين الجدول التالي بعض حقول HTTP وقيمها.
