• التابع وحيد الاتجاه: إذا كان لدينا x فإنه من السهل حساب مجموع حجوم الأغراض ضمن الحقيبة. أما إذا كان لدينا حجم الحقيبة s فإنه من الصعب تحديد صيغة ملائمة لـ x لتحديد الأغراض التي تملئ تمامًا الحقيبة: يوجد 2k صيغة ممكنة ويجب تجربتها كلها لتحديد الحل المناسب.
• التابع وحيد الاتجاه ذو المصيدة: إذا كانت حجوم الأغراض ممثلة بشكل متزايد Superincreasing tuple وكان لدينا ai ≥ a1 + a2 + ... + ai−1 فإنه يمكن استخدام الخوارزمية التالية لحل المسألة:
for (i = k down to 1) {
if (s >= ai) {
xi = 1
s = s – ai
}
else xi = 0
}
مثال:
• a = [2, 3, 6, 12, 25, 50, 100, 200]
• s = 139
• Steps:
• 139 < 200 → x8 = 0
• 139 > 100 → x7 = 1 s = 39
• 39 < 50 → x6 = 0
• 39 > 25 → x5 = 1 s = 14
• 14 > 12 → x4 = 1 s = 2
• 2 < 6 → x3 = 0
• 2 < 3 → x2 = 0
• 2 = 2 → x1 = 1 s = 0
